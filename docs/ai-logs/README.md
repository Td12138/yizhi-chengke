# AI 对话快照

> 赛道硬性提交物：须提交 AI 对话历史的 prompt 快照。
> 纪律：**每次与 AI 的核心会话结束即落盘，不事后补写。**

## 命名

`YYYY-MM-DD-<阶段>-<主题>.md`

## 单份结构

| 节 | 内容 |
|---|---|
| 目标 | 这次会话要实现什么 |
| 关键 prompt | 实际发出的指令（原文，可截断无关寒暄） |
| AI 输出摘要 | 拿到的方案/代码要点 |
| 我的判断 | 采纳了什么、否决了什么、为什么 |
| 落地结果 | 对应提交主题（可在 `git log` 中检索） |

| 要求 | 本目录对应 |
|---|---|
| 至少 3 个核心功能迭代的**完整 Prompt 链**（我的提问 + AI 建议 + 我如何引导修 Bug） | `2026-11-17-E1-核心迭代Prompt链.md` 的第 1/2/3 条链：AI 批改、P0 表达式注入修复、mock 命题分流 + 单文件版配置 |

| 引导修 Bug 的过程 | 链 1 的流式切片、链 2 的三层白名单与复验脚本、链 3 的 `expect` 异常与 portable 配置 |
